# Contributing

Thanks for helping other Mac users learn cloud computing!

- Open an **Issue** to report an outdated setting, broken link, or a Mac-specific problem.
- Open a **Pull Request** for a suggested fix, clarification, or useful optional tip.
- Describe your macOS version, tool version, and the course/lab context where relevant.
- Keep recommendations optional unless a particular course explicitly requires them.
- Avoid uploading credentials, API tokens, SSH private keys, personal data, or screenshots showing secrets.
- Only contribute text and images you have permission to share under the repository's license.

**Important:** Course instructions always take precedence over this independent student guide.
